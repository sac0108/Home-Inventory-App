# HomeSphere AI - Smart Household Inventory Management

A high-fidelity, enterprise-style static web prototype for household inventory operations, shopping intelligence, analytics, family collaboration, and smart notifications.

## Features
- Animated onboarding/authentication
- Dashboard with KPI cards and interactive Chart.js charts
- Inventory CRUD (add/edit/delete/quantity update/search)
- Product form validation and modal UX
- Shopping list management with reorder + purchased states
- Notifications center with read/unread flow
- Family management and role assignment
- Analytics dashboard with responsive charts
- Dark mode with localStorage persistence
- Responsive desktop sidebar + mobile bottom navigation

## Run Locally
1. Download or clone the files.
2. Open `index.html` in any modern browser.
3. No build tools, backend, or package installs required.

## GitHub Pages Deployment
1. Create a new GitHub repository named `household-inventory-app`.
2. Upload all project files to the `main` branch root.
3. Open repository **Settings**.
4. Go to **Pages**.
5. Under **Build and deployment**, select:
   - **Deploy from a branch**
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.
7. Access your site at:
   `https://YOUR_USERNAME.github.io/household-inventory-app/`
